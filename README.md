## 📈 Project 1: Simple Linear Regression (Vehicle $CO_2$ Emissions)
A production-ready implementation of a Simple Linear Regression model to predict a vehicle's Carbon Dioxide ($CO_2$) emissions based on its engine size using the Canadian Fuel Consumption dataset.

### 🛠️ Tech Stack & Tools
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Scikit-learn
* **Environment:** Jupyter Notebooks / VS Code

### 📊 Key Results Achieved
* **Dataset Split:** 80% Training, 20% Testing
* **Model Accuracy ($R^2$ Score):** **0.76 (76%)**
* **Mean Absolute Error (MAE):** 24.10 g/km
* **Root Mean Squared Error (RMSE):** 31.40 g/km
